cd shopflow

Distributed Systems Patterns
🔄
Saga Orchestration

Coordinates distributed order processing across payment and inventory, including compensation flows, timeout recovery, and Dead Letter Queue handling.

📬
Transactional Outbox

Ensures reliable Kafka event publishing alongside database transactions, avoiding dual-write inconsistencies. Safe across 2 order-service replicas via FOR UPDATE SKIP LOCKED.

🔑
Idempotent Consumer

Prevents duplicate processing during retries and message redelivery using the Inbox pattern and client-generated idempotency keys.

⚡
Event-Driven Messaging

Kafka-based service communication using Avro serialization and Apicurio Schema Registry for shared event contracts.

🛡️
API Gateway

Provides a single entry point with circuit breaker protection, Keycloak JWT authentication, and correlation ID propagation.

🏗️
Hexagonal Architecture

Separates order-service domain logic from infrastructure concerns, keeping the core independent of Quarkus, JPA, and Kafka.

📊
Observability

Prometheus, Grafana, and Loki provide infrastructure and application monitoring, with custom metrics for Saga outcomes, duration, and Outbox activity.

🚀
Kubernetes Deployment

GitOps delivery via GitHub Actions and Argo CD for automated Kubernetes deployment on Minikube.
